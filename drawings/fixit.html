Alternatives

Hardware agrees with Rocrail

Leave Rocrail unchanged and update the address document instead.

Planned or unused output

Leave the output unchanged until it is needed.

Change the decoder instead

Decoder programming is separate from changing Rocrail.

After a change

  1. Test the affected signal or output with the tracks clear.
  2. Obtain a fresh copy or export of the saved plan XML. From the project folder run python pdfcheck.py "DMJK-Adresser.pdf" "PLAN.xml", replacing PLAN.xml with that file. This requires pdftotext on PATH and overwrites pdfcheck.txt and drawings\error.json.
  3. Run python drawings\stations.py "PLAN.xml" with the same plan to regenerate the drawings and this guide.

Alternative: import an edited XML plan

Upload transfers the whole plan but does not activate it. These steps use the older Rocview workflow.

  1. Edit a current copy of the active plan. Save it with a filename that does not already exist in the server's working directory, such as DMJK-fixed.xml.
  2. Connect Rocview to the Rocrail server. Select File → Upload and choose the edited XML file.
  3. Check that the uploaded file exists in the server's Rocrail working directory.
  4. In File → Rocrail Properties → General, note the current Track plan file. Change it to the uploaded filename on the server and click OK.
  5. Restart the Rocrail server and reconnect Rocview. Check the changed fields and test the affected equipment with the tracks clear.
  6. To undo the import, restore the previous Track plan file setting and restart the server.
