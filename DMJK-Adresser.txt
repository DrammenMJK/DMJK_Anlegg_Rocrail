Dvergsignal kontroll koder (fjernes etterhvert):

Dm0[x]                      Modus 0: Normal drift

Dm1[x]                      Modus 1: Hovedsignal Rødt

Dm2[x]                      Modus 2: Hovedsignal Rødt, Dvergsignal i "Lokal Skifting" (øvre høyre lys på)

Ds[x]                       Sett Stopper (Gul) for all dverger som er i Kjør (Grønn) (brukes i tilfelle aspekt > 16)

[x] = 1-n i tilfelle det er flere kommandoer som håndterer hver sine signal

Signaldekoderne konfigureres med en CV konfigurasjonsfil med navn OpenDec2_NNvVV_SS...S_AA.csv
der: NN = konfigurasjon ID nummer (CV 530)

           VV = konfigurasjon Versjon (CV 531).
           SS...S = forkortet beskrivelse for signaltyper i konfigurasjonen
           AA = antall aspekt brukt i konfigurasjonen (CV 553) - det er 2 aspekt per adresse. >16 aspekt krever program versjon 14+ (CV 7)

Kofigurasjonsfilen er en .csv fil med 2 parametere per linje: CVnummer, Verdi (desimaltall) fulgt av valgfri beskrivelse (uten komma  mellom)

Kofigurasjonsfilen laget for bruk med programmeringsfunksjonen i Rocrail, men andre programmerere kan sikkert også brukes.

Kofigurasjonsfilen starter typisk med filnummer og versjon, slik:

530, 24 Config file number

531, 3 Config version 20260118

Deretter følger et antall CVer som definerer standard dekoderoppsett for DMJK. Eneste CV som varierer er CV 553 NoOfAspects

som definerer hvor mange aspekt dekoderen håndterer. Lovlige verdier er: 8, 16, 24, 32 og 48 (som krever 4-24 adresser)

553, 32 NoOfAspects: 8-48 in increments of 8 (4-24 addresses)

Etter standard oppsettblokken følger antall aspekter som er definert:

565, 3 Aspect 0: U1 Red         Bitmønster som definer hvilke utganger som skal styres

566, 1 Pattern                  Bitmønster som definer på/av tilstand for utgangene

567, 0 Blink                    Bitmønster som definer hvilke utganger som skal blinke

716, 0 Dwarf                    Bitmønster som definer på/av tilstand for lysene i dvergsignal

Dvergsignal bitmønster: bit 0-3 velger dverg 1-4, bit 4 er øvre høyre lys, 5 er nedre høyre, 6 er nedre venstre og 7 er øvre venstre

Standard dvergsignal aspekt er Red, Green, Yellow (nedre venstre og øvre høyre) og White (øvre høyre)

Etter siste vanlige aspekt kommer et tilsvarende oppstart/reset aspekt i CV 712, 713, 714 og 747.

Til sist kommer:

715, 0 NoDimmMask               Bitmønster som definer hvilke utganger som ikke skal dimmes, typisk brukt for rele

520, 13 Reset decoder           Reset kommando som gjør at dekoderen tar i bruk den nye konfigurasjonen umiddelbart

Dekoderen har 5-lys logikk som slukker forsignalet ved rødt hovedsignal på utgang 1-5: trigges når CV 565 = 31 og CV 568 = 7
